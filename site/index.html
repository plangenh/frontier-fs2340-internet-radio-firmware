What is supported by evidence?

The examined original contains 15 language tables with 1,056 entries each and 65 graphics records. Complete manufacturer resources are not distributed here. The public data file contains short menu labels and technical research metadata.

A callback with a pointer to another descriptor may indicate a submenu link. Such edges remain static candidates until dispatch behavior is confirmed. Dynamic station, podcast, and network lists are not fully covered.

Roadmap: firmware personalization

We aim to enable custom text, icons, and colors on compatible radios. Resource formats are understood, and a small text modification was reported working. A reliable customization release is not available yet.

Next: recover the test device, preserve loader-command boundaries during packaging, and validate minimal changes on hardware with a tested recovery path. Broader customization follows those milestones. No release date is committed.
